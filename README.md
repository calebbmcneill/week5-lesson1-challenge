# week5-lesson1-challenge
Contains the Weather Report challenge for Week 5 Lesson 1: A simple program for getting a general description of the weather in any US city.

### Prerequisites
- Python 3.9+

### Installation
```bash
GitHub repo: "week5-lesson1-challenge"
git clone https://github.com/calebbmcneill/week5-lesson1-challenge
cd week5-lesson1-challenge
python3 -m venv .venv
.venv/Scripts/activate.ps1

### Usage
python3 main.py
